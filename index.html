    도움말
    로컬 데이터는 JSONL에 저장된 HTTP 요청 기록과 규칙 기반 탐지 결과입니다. 의심 신호가 침해 확정을 뜻하지는 않습니다.
    조회 범위 밖의 이벤트나 규칙에 해당하지 않는 위험은 표시되지 않을 수 있습니다. 
    모의 실습은 브라우저의 합성 데이터만 변경하며 실제 키나 요청을 차단하지 않습니다.
    로컬 테스트 키 관리는 로컬 서버의 키를 실제로 발급·폐기하고 HTTP 인증을 검증합니다. 운영 키와 외부 클라우드는 연결하지 않습니다.
