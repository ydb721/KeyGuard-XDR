# UI 설계 명세 · KeyGuard XDR v0.1

## 디자인 목표

실제 기업 업무 콘솔의 가독성과 우선순위 작업에 적합한 UI를 지향한다. 과도한 네온·블루/네이비·복잡한 장식 그래프를 배제하고, 따뜻한 Stone 배경과 차분한 Emerald를 핵심 색으로 사용한다.

## 화면별 책임

- **Overview**: 현재 사건 현황, 우선 처리 큐, 데이터 출처 요약, 시간대 추이, 규칙별 건수.
- **Incidents**: 심각도·상태 필터, 검색, 사고 상세 정보, 탐지 근거, 조사/모의 격리 작업.
- **Detection Rules**: 다섯 가지 시연 규칙과 설명. 수정/운영 적용 없음.
- **Assets**: 사건에 연결된 가상 자산을 실시간으로 집계해 표시.
- **Response Lab**: 3개 시나리오를 가상 이벤트로 생성하고 상태 전환 확인.
- **Audit Log**: 감사 이벤트 필터, CSV 내보내기.

## UX 원칙

- `DEMO / SIMULATION` 표기는 언제나 눈에 보이게 유지.
- 연결 실패, 정보 미확인, 침해 확정 같은 상태를 과장하지 않음.
- 새로고침 시 사건 데이터는 초기화되며, 테마 설정만 가능할 때 로컬에 유지.
- 표에는 사건 ID, 심각도, 상태, 영향 자산, 시각을 함께 제공.
- 동적 필터는 버튼의 `aria-pressed`로 선택 상태 제공.
- 중요한 조작은 사용자 버튼으로 실행하며 자동 대응 없음.
- 작은 화면에서는 표를 가로 스크롤 가능하게 유지.
