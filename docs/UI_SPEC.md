## 디자인 목표

## 화면별 책임

- **보안 현황 (Detect)**: 공통 사고 상태에서 계산한 KPI와 최근 탐지 사고.
- **사고 분석 (Investigate)**: 심각도·상태 필터, 검색, 규칙·증거·영향 자산을 포함한 사고 상세, 조사/모의 대응.
- **대응 및 검증 (Respond & Verify)**: 3개 시나리오 생성, 모의 대응 결과, 조치 이력 및 CSV 내보내기.

## UX 원칙

- `DEMO / SIMULATION` 표기는 언제나 눈에 보이게 유지.
- 연결 실패, 정보 미확인, 침해 확정 같은 상태를 과장하지 않음.
- 새로고침 시 사건 데이터는 초기화되며, 테마 설정만 가능할 때 로컬에 유지.
- 표에는 사건 ID, 심각도, 상태, 영향 자산, 시각을 함께 제공.
- 동적 필터는 버튼의 `aria-pressed`로 선택 상태 제공.
- 중요한 조작은 사용자 버튼으로 실행하며 자동 대응 없음.
- 작은 화면에서는 표를 가로 스크롤 가능하게 유지.
