# UI 설계 명세 · KeyGuard XDR v0.5.0

## 디자인

Pearl Lilac을 사용합니다. 라이트는 `#F7F8FD` 배경·흰 카드·`#282B3A` 본문·`#7868E8` 주요 상호작용, 다크는 부드러운 차콜/보랏빛 회색과 라일락 포인트를 사용합니다. 성공은 초록, 주의는 주황, 오류는 빨강을 유지합니다.

| 역할 | Light | Dark |
|---|---|---|
| 배경 | `#F7F8FD` | `#20202B` |
| 카드 | `#FFFFFF` | `#303043` |
| 테두리 | `#DFE3F1` | `#48485F` |
| 본문 | `#282B3A` | `#F1F1FA` |
| 라일락 포인트 | `#7868E8` | `#A496FF` |

텍스트·상태·포커스는 충분한 대비를 유지한다. 필터는 `aria-pressed`, 테마 버튼은 다음 동작의 aria-label을 제공한다. 오류·확인 불가·빈 결과는 서로 다른 상태로 표현하며 성공으로 과장하지 않는다.

## 메뉴

- **Detect**: 로컬 데이터 출처, 연결 상태, 요약 KPI, 탐지 목록과 원본 이벤트를 한눈에 보여 줍니다.
- **Investigate**: 상세 패널은 요약 → 탐지 근거 → 상세 정보 → 한계 및 조치 순서입니다. 로컬 탐지는 읽기 전용이고, 브라우저 모의 사고만 조사·모의 대응 상태를 바꿉니다.
- **Respond**: 운영자 인증 → 키 상태/발급·폐기 → 실제 접근 검증 → 로컬 키 감사 순서로 배치합니다. 모의 실습은 별도 영역입니다.

## Respond 접근성·반응형

발급 원문은 기본 마스킹되고 명시적 보기/가리기를 제공하며 Enter/Space 키로도 조작할 수 있습니다. 원문은 메모리 외 저장소에 두지 않습니다. 375px에서는 키 관리 입력·버튼이 카드 폭에 맞는 단일 열이고, 로컬 키 감사는 시각·감사 ID·작업·결과·키 ID를 읽을 수 있는 카드형입니다. 데스크톱은 인라인 작업 배치를 유지합니다.

Moon/Sun 아이콘 버튼은 다음 테마 동작을 aria-label로 알리고 선택값은 localStorage에 보존합니다. 아코디언·일반 섹션 토글·추가 모달은 제공하지 않습니다.
