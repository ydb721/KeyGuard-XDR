## 디자인 목표

## 화면별 책임

- **보안 현황 (Detect)**: 로컬 조회 이벤트·탐지·실패 수, 규칙별 수, 최근 탐지·이벤트. 모의 모드에서는 기존 KPI·합성 사고.
- **사고 분석 (Investigate)**: 로컬 탐지 검색·심각도 필터·규칙·구간·사유·근거·자산을 읽기 전용으로 표시. 상태 필터와 조사/모의 대응은 모의 출처에만 제공.
- **대응 및 검증 (Respond & Verify)**: 3개 시나리오 생성, 모의 대응 결과, 조치 이력 및 CSV 내보내기.

## UX 원칙

- 상단 배너·출처 컨트롤·상단바·사이드바에 현재 로컬/모의 출처를 명확히 표시. Respond 화면으로 자동 전환 시 모의 출처 안내.
- 연결 실패, 정보 미확인, 침해 확정 같은 상태를 과장하지 않음.
- 새로고침 시 브라우저 모의 사건만 초기화되며 서버 JSONL은 유지. 테마 설정은 가능할 때 로컬에 유지.
- 표에는 사건 ID, 심각도, 상태, 영향 자산, 시각을 함께 제공.
- 동적 필터는 버튼의 `aria-pressed`로 선택 상태 제공.
- 중요한 조작은 사용자 버튼으로 실행하며 자동 대응 없음.
- 작은 화면에서는 표를 가로 스크롤 가능하게 유지.

## 버전 네이밍

애플리케이션 명: **KeyGuard XDR**. 현재 UI 개발 버전 **v0.4.0**.

v0.4.0은 기존 Stone+Emerald 색과 3개 화면을 유지한다. 연결 상태는 Loading/Connected/Empty/Error/Unavailable/Invalid Response로 구분하고 한국어 설명을 함께 표시한다. 오류는 0건으로 표시하지 않으며 이전 데이터가 있으면 마지막 정상 조회 시각과 최신 아님을 표시한다. API는 최대 100건 조회이므로 누적 총계·실제 HIGH 위험도를 만들어 표시하지 않는다.

근거 목록은 이벤트 ID·유형·상태 코드·UTC 시각을 연결하고 현재 범위 밖이면 확인 불가 문구를 표시한다. API 문자열은 이스케이프한다. 키보드 Enter/Space로 행을 선택할 수 있고 작은 화면에서는 표 내부 가로 스크롤과 테마 버튼의 한국어 라벨을 유지한다. 모의 사고·감사 상태와 로컬 조회 상태는 분리하며 새로고침 시 모의 상태는 초기화되고 테마만 저장된다.
