# KeyGuard XDR v0.5.0 프로젝트 범위

## 완료된 구현

- Pearl Lilac 라이트·다크 테마, 3개 메뉴 Detect / Investigate / Respond, 반응형 모바일 UI
- localhost JSONL 이벤트 저장·조회와 실제 HTTP 인증 결과 기록
- KG-R001, KG-R002 로컬 HTTP 이벤트 탐지 및 근거 연결 읽기 전용 분석
- 브라우저 모의 사고 3종, 조사·모의 대응·감사·CSV 내보내기
- 별도 로컬 실습 키의 운영자 인증, 명시적 확인, 발급·폐기·재발급, HTTP 200/401 검증, 영속 감사
- 키 원문 기본 마스킹과 메모리 전용 일회성 표시, 응답 유실의 확인 불가 처리

## 규칙 범위

- KG-R001: 동일 자산에서 60초 내 인증 실패 5건
- KG-R002: 동일 자산에서 120초 내 실패 3건 이상 뒤 인증 성공
- KG-R003: 별도 합성 Cloud·Endpoint Fixture에서만 300초 상관분석을 검증합니다. 실제 JSONL 저장소와 일반 탐지 API에는 넣지 않습니다.

## 초기 계획과 구분되는 한계

실제 Cloud·Endpoint 수집, 운영 자격증명 또는 운영 키 폐기, 외부 서비스 차단, 자동 대응, 실시간 탐지 엔진은 구현하지 않았습니다. 로컬 탐지는 읽기 전용이며 모의 대응은 브라우저 내부 상태만 바꿉니다.

v0.1은 UI/상태 관리, v0.2는 로컬 이벤트 영속 저장, v0.3은 규칙·합성 상관분석, v0.4는 로컬 근거 UI 연결, v0.5는 독립 로컬 실습 키의 수명주기와 감사 검증을 추가했습니다. 이 결과는 운영 보안 효과의 증거가 아닙니다.
