# KeyGuard XDR 로드맵

| 버전 | 구현 이력 |
|---|---|
| v0.1.0 | 초기 SOC UI, 모의 사고·대응·감사·테마 |
| v0.1.1 | 3개 메뉴 통합과 기존 동작 회귀 검증 |
| v0.2.0 | localhost HTTP 이벤트 API와 JSONL 저장 |
| v0.3.0 | KG-R001/R002 규칙, KG-R003 합성 Fixture 검증 |
| v0.4.0 | 로컬 이벤트·탐지 근거의 Detect/Investigate 연결 |
| **v0.5.0 현재** | 운영자 인증 기반 로컬 실습 키 발급·폐기·재발급, 실제 200/401 검증, 감사 영속성, Pearl Lilac/모바일 UX |
| v1.0.0 계획 | 배포 재현성, 보안 검토, 포트폴리오 증적 정리 |

v0.5.0은 로컬 교육 범위의 완료 버전입니다. 키 원문은 응답에서만 제공하고 상태 파일에는 해시·감사만 남깁니다. 실제 운영 키, 외부 API, 자동 대응, Cloud·Endpoint 수집은 제공하지 않습니다.

v1.0.0은 완료되지 않은 향후 계획입니다. 운영 환경 연결 또는 실제 보안 조치는 별도 요구사항과 보안 검토 없이는 범위에 포함하지 않습니다.

v1.0.0 완료 기준은 독립 실행 절차 재현, 전체 자동·브라우저 검증 기록, 문서와 구현 계약의 일치, 민감정보 비포함 확인, 로컬 교육 범위의 한계 명시입니다. 이는 외부 배포·운영 연동 완료를 뜻하지 않습니다.
