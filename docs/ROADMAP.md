# 후속 개발 로드맵 · KeyGuard XDR

| 버전(예정) | 개발 목표 | 완료 판단 기준 |
|---|---|---|
| **v0.1.0 현재** | Stone + Emerald UI, 다크 모드, 사건·감사 시뮬레이션 | 6개 화면 이동, 모의 워크플로 테스트 통과 |
| v0.2.0 | 테스트용 API 및 이벤트 수집 서버 | 정상·실패 요청이 서버에서 생성·저장·조회됨 |
| v0.3.0 | 규칙 기반 탐지 + 다중 출처 상관분석 | 정상·비정상 이벤트에 대한 자동 판정과 판단 근거 검증 |
| v0.4.0 | 사고 조사 UI와 실제 API 연결 | 화면이 브라우저 가상 상태 대신 API 데이터 반영 |
| v0.5.0 | 테스트 키 폐기·재발급 + 검증 | 구 키 401·신 키 성공, 권한/감사 이력 검증 |
| v1.0.0 | 배포·보안 테스트·포트폴리오 증적 | 독립 실행 및 동일 조건 재현, 문서·실행 결과 제공 |

- 후속 버전 번호는 개발 계획이며 실제 완료를 보증하지 않는다.
- 외부 클라우드 계정과 운영 키를 사용하지 않고 자체 테스트 서버와 샌드박스를 사용한다.
- 먼저 정상 데이터 수집의 정확성을 확보한 뒤 탐지·대응으로 확장한다.
- AI 기반 분석은 규칙 기반 테스트가 충분히 검증된 뒤 선택적으로 도입한다.
